# Self-hosted fonts

- `inter-latin-variable.woff2`: Inter (Rasmus Andersson), weights 400 to 700, Latin subset.
- `plus-jakarta-sans-latin-variable.woff2`: Plus Jakarta Sans (Tokotype), weights 600 to 800, Latin subset.

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org). They are
self-hosted so the apps work offline and make no request to Google Fonts
(`10-screens-shared.md`, "Type, spacing and shape").
